# Hobby_Tracker — Клиентская часть

Данный репозиторий содержит клиентское приложение проекта **Hobby_Tracker**. Это фронтенд-часть системы, которая отвечает за графический интерфейс и взаимодействует с сервером посредством API-запросов для получения и синхронизации данных.

API: https://github.com/griy-rerere/hobby-tracker-api

## 📊 Графический интерфейс (GUI)

Интерфейс приложения построен на базе библиотеки **Dear ImGui**. В нем отображается подробная статистика пользователя, которая включает:
* Учет и разделение времени сессий;
* Сортировку данных по различным параметрам;
* Наглядные диаграммы и другие информационные графические элементы.

## 🔐 Регистрация и авторизация (JWT)

В проекте реализована система аутентификации пользователей на основе **JWT (Access/Refresh)**:

* **Регистрация:** Пользователь создает логин и пароль в GUI-формах приложения. Данные отправляются на сервер, где аккаунту присваивается уникальный ID для последующей валидации при входе.
* **Авторизация и запросы:** При входе клиент получает JWT-токены. Для доступа к защищенным данным приложение автоматически прикрепляет токен к заголовкам HTTP-запросов.
* **Обновление сессии:** Процесс валидации и обновления истекших токенов (Refresh) происходит автоматически на стороне клиента, незаметно для пользователя.


## 🛠 Технологический стек и Зависимости

* **Язык программирования:** C++
* **Графический интерфейс:** Dear ImGui
* **Бэкенд рендеринга:** GLFW + OpenGL3
* **Система сборки:** CMake
* **Менеджер пакетов:** vcpkg

## 🚀 Установка и сборка проекта (Windows)

Для сборки проекта на Windows используются **Visual Studio Code** и менеджер пакетов **vcpkg** для автоматического управления зависимостями (Dear ImGui, GLFW).

### Шаг 1. Подготовка окружения
Убедитесь, что у вас установлены:
* [Visual Studio Code](https://code.visualstudio.com/) с расширениями **CMake Tools** и **C/C++** (от Microsoft).
* Компилятор C++: либо **MSVC** (Visual Studio Build Tools), либо **MinGW** (например, через MSYS2).
* [CMake](https://cmake.org/download/) (убедитесь, что при установке была выбрана опция добавления в системный PATH).

### Шаг 2. Установка vcpkg и зависимостей
Если у вас еще не установлен `vcpkg`, выполните следующие команды в PowerShell:

```powershell
# 1. Перейдите на диск C: (или в удобную вам директорию без пробелов в пути)
cd C:\

# 2. Клонирование репозитория vcpkg
git clone https://github.com/microsoft/vcpkg

# 3. Переход в папку и инициализация
cd vcpkg
.\bootstrap-vcpkg.bat

# 4. Установка зависимостей (укажите ваш триплет: x64-windows для MSVC или x64-mingw-dynamic для MinGW)
.\vcpkg install imgui[glfw-binding,opengl3-binding]:x64-windows

### Шаг 2. Установка vcpkg и зависимостей
Если у вас еще не установлен `vcpkg`, склонируйте его официальный репозиторий и настройте зависимости:

```bash
# Клонирование репозитория vcpkg в C:/
git clone https://github.com/microsoft/vcpkg
cd vcpkg

# Инициализация vcpkg
.\bootstrap-vcpkg.bat

# Установка необходимых графических библиотек, необходимое подтянется само
.\vcpkg install imgui[glfw-binding,opengl3-binding] glfw3
```

### Шаг 3. Клонирование и настройка проекта
1. Склонируйте данный репозиторий с минимальным набором файлов для сборки:
   ```bash
   git clone https://github.com/Zer0Dash/Front_Hobby_Tracker
   cd Front_Hobby_Tracker
   ```
2. Откройте папку проекта в **Visual Studio Code**. Не открывайте родительскую папку, иначе CMake не найдет конфигурационные файлы.

### Шаг 4. Сборка проекта

⚠️ **Важно:** Убедитесь, что в Visual Studio Code открыта именно папка `Front_Hobby_Tracker` (а не родительская папка `Hobby_tracker`), иначе CMake не найдет конфигурационные файлы.

#### Способ А: Через интерфейс VS Code (Рекомендуется)
1. Откройте палитру команд (`Ctrl` + `Shift` + `P`) и выберите **`CMake: Configure`**.
2. При первом запуске VS Code попросит выбрать набор инструментов (Kit). Выберите ваш компилятор (например, `GCC x.x.x MinGW` или `Visual Studio Community`).
3. Чтобы CMake автоматически нашел библиотеки `vcpkg`, добавьте в файл `.vscode/settings.json` (или настройте через интерфейс CMake) следующий параметр:
   ```json
   "cmake.configureSettings": {
       "CMAKE_TOOLCHAIN_FILE": "C:/vcpkg/scripts/buildsystems/vcpkg.cmake"
   }

(Замените C:/vcpkg на реальный абсолютный путь к папке, куда вы клонировали vcpkg).
4. Нажмите кнопку Build (значок молотка 🛠️) в нижней синей панели VS Code или нажмите клавишу F7.

#### Способ Б: Через терминал (Ручной)
Если вы предпочитаете командную строку, выполните следующие команды в терминале VS Code, находясь в корне папки Front_Hobby_Tracker:

```bash
    # 1. Создаем и переходим в папку сборки
    mkdir build && cd build

    # 2. Конфигурируем проект, указывая путь к тулчейну vcpkg 
    # (Обязательно замените C:/vcpkg на реальный путь к вашей папке vcpkg)
    cmake .. -DCMAKE_TOOLCHAIN_FILE="C:/vcpkg/scripts/buildsystems/vcpkg.cmake"

    # 3. Собираем проект
    cmake --build . --config Release  
```

После успешной сборки исполняемый файл появится в папке build. Для запуска нажмите кнопку Play ▶️ рядом с кнопкой сборки в VS Code или запустите .exe файл вручную.
